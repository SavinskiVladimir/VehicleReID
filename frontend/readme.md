# Vehicle Re-ID — клиентская часть

Веб-интерфейс для загрузки изображения, выбора обнаруженного ТС и
просмотра результатов поиска по базе, журнала поиска с повторным поиском
и базы наблюдений (функции 1, 2, 7, 8, 9 из Таблицы 1.3 ТЗ). React + Vite, без TypeScript, без UI-фреймворка
(собственная дизайн-система на CSS custom properties).

## Установка

```bash
cd frontend
npm install
```

## Запуск в режиме разработки

Backend должен быть уже запущен на `http://localhost:8000` (см.
`backend/README`-инструкции / `uvicorn backend.app.main:app --reload`
из корня проекта).

```bash
npm run dev
```

Откроется `http://localhost:3000`. Запросы к `/api/*`
автоматически проксируются на backend (см. `vite.config.js`) — CORS
настраивать не нужно.

## Сборка для продакшена

```bash
npm run build
```

Результат — в `dist/`. На этапе развёртывания (docker-compose +
reverse-proxy) эта папка будет отдаваться статикой тем же сервером,
что проксирует `/api`/`/files` на backend — на одном origin, как и в
dev-режиме.

## Переменные окружения

См. `.env.example`. В большинстве случаев (dev через Vite-прокси,
прод через reverse-proxy на одном origin) ничего настраивать не нужно
— `VITE_API_BASE_URL` нужен только если backend обслуживается на
ДРУГОМ origin, отличном от фронтенда.

## Структура

```
src/
├── api/client.js            - axios-клиент, все обращения к backend
├── components/              - переиспользуемые UI-компоненты
├── pages/
│   ├── SearchPage.jsx        - основной поток: загрузка, детекция, выбор, поиск
│   ├── SearchHistoryPage.jsx - ИСТОРИЯ ПОИСКА: журнал выполненных поисков, повторный поиск
│   └── ObservationsPage.jsx  - БАЗА НАБЛЮДЕНИЙ: записи, в которых ищем (просмотр, удаление)
└── hooks/useAdminToken.js   - хранение admin-токена (localStorage)
```

## Admin-функции

Сохранение (`POST /api/observations`), удаление наблюдений, удаление записей
истории поиска и её очистка требуют
admin-токен (см. `backend/app/auth.py`, заголовок `X-Admin-Token`).
При первом admin-действии интерфейс показывает модальное окно для
ввода токена; дальше он хранится в `localStorage` браузера на время
сессии — повторно вводить не нужно.

## Дизайн

Палитра — оттенки белого и синего (светлая тема, оптимизированная под
проектор). Токены цвета/типографики — в `src/index.css`. Данные,
подлежащие измерению (similarity, координаты bbox), набраны
моноширинным шрифтом (JetBrains Mono) для выравнивания в таблицах —
не декоративный приём, а функциональный.
